# 🎓 Live Classroom AI Feedback System  

An **AI-powered classroom monitoring tool** that detects **real-time student engagement** using **FER+** and **OpenCV**.  
The system analyzes facial expressions through the webcam and classifies emotions into clear engagement states — helping educators understand how students truly feel during a session.  

---

## 🧩 Engagement States
- 😄 **Engaged** – Actively attentive and focused  
- 😐 **Bored / 😤 Frustrated** – Disinterested or mentally fatigued  
- 😕 **Confused** – Struggling to follow or understand  
- 😶 **Neutral** – Passive or idle (optional state if desired)

---

## ⚙️ Features
- 🎥 **Real-time face detection** using Haar Cascade  
- 🧠 **Emotion recognition** powered by FER+ and TorchVision  
- 🪄 **Smart mapping** of emotions to engagement states  
- ⚡ **Lightweight performance** — runs entirely on CPU  
- 📊 **Designed for classroom analytics** and educational feedback

## 🏫 About
**Live Classroom AI Feedback System** provides educators with a **non-intrusive way** to monitor classroom engagement.  
By analyzing facial cues in real time, it delivers actionable insights on student emotions — enabling adaptive teaching and better learning outcomes.
