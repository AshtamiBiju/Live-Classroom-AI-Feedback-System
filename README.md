# 🎓 Live Classroom AI Feedback System

A real-time emotion and engagement detection system built using **FER+** and **OpenCV**. 
It classifies live webcam faces into four engagement states:

- 😄 Engaged  
- 😐 Bored / 😤 Frustrated   
- 😕 Confused  

## 🚀 Features
- Real-time face detection using Haar Cascade  
- Emotion recognition with FER+ FER Builtin model  
- Smart mapping of emotions to engagement states  
- Lightweight — runs on CPU  

## 🧠 Tech Stack
- Python
- PyTorch
- OpenCV
- Torchvision
